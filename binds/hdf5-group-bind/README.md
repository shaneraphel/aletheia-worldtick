# HDF5 group bind

An HDF5 group is registered only after it names an hdf5 id, so two groups cannot append into one unsigned list.

## Demo

https://shaneraphel.github.io/hdf5-group-bind/

## Resource

Playable tape: `schema/bind.schema.json` plus `fixtures/sample.json`.
A named schema without a fixture is not a resource.
