# rosbag2 message bind

A rosbag2 message is registered only after it names a bag2 id, so two messages cannot append into one unsigned list.

## Demo

https://shaneraphel.github.io/rosbag2-message-bind/

## Resource

Playable tape: `schema/bind.schema.json` plus `fixtures/sample.json`.
A named schema without a fixture is not a resource.
