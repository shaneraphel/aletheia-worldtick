# GeoParquet feature bind

A GeoParquet feature is registered only after it names a geoparquet id, so two features cannot append into one unsigned list.

## Demo

https://shaneraphel.github.io/geoparquet-feature-bind/

## Resource

Playable tape: `schema/bind.schema.json` plus `fixtures/sample.json`.
A named schema without a fixture is not a resource.
