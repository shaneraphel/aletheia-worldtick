# GeoTIFF tile bind

A GeoTIFF tile is registered only after it names a geotiff id, so two tiles cannot append into one unsigned list.

## Demo

https://shaneraphel.github.io/geotiff-tile-bind/

## Resource

Playable tape: `schema/bind.schema.json` plus `fixtures/sample.json`.
A named schema without a fixture is not a resource.
