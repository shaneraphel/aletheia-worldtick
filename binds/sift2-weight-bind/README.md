# SIFT2 weight bind

A SIFT2 weight is registered only after it names a sift2 id, so two weight maps cannot append into one unsigned list.

## Demo

https://shaneraphel.github.io/sift2-weight-bind/

## Resource

Playable tape: `schema/bind.schema.json` plus `fixtures/sample.json`.
A named schema without a fixture is not a resource.
