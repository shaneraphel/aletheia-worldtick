# Airflow LLM bind

An Airflow LLM branch is registered only after it names an llm id, so two branches cannot append into one unsigned list.

## Demo

https://shaneraphel.github.io/airflow-llm-bind/

## Resource

A named schema without a fixture is not a resource.
